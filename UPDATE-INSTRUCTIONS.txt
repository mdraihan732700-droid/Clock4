MINIMAL CLOCK — VERSION 5 (MODE 4 MINUTE TICK)

Replace these files in the ROOT of your existing Clock4 GitHub repository:
- index.html
- sw.js

Do not create a folder. Keep both files beside manifest.webmanifest and the icons. Commit to main. Wait for Pages to publish, then open the website once in Chrome. The service worker cache version is updated to v5.

Behaviour: Modes 1–3 keep their existing once-per-second tick controlled by “Tick sound (Modes 1–3)”. Mode 4 plays one tick at the start of each new minute, controlled separately by “Minute tick (Mode 4)”. Both use the existing volume slider. The first opening of Mode 4 does not make an immediate tick; it waits for the next minute boundary.
